# Japanese Readability Guidelines

日本語版の文章題は「正確な翻訳」だけでは足りない。小学生が読む前提では、情報量の分け方を先に設計する。

## 基本方針

- 1 文に入れる動作は 1 つまで。
- 1 文はできれば 30 文字前後に抑える。
- 数字、単位、聞かれている量をはっきり出す。
- 最後の文は短い問いにする。例：`はじめは何個？`、`1 箱は何個？`
- build 关的题干里优先写 `式を作ろう`，不要频繁写 `方程式を作ろう`。

## 避けたい表現

- `定員`、`実際の人数`、`総数`、`余計なカード` など、読み負荷が高い語。
- 人物、动作、条件、问题全挤在一个长句里。
- 只把中文/英文直译成日语，但不按日语小学生的阅读节奏重排信息。

## 推荐替换

- `最初` → `はじめ`
- `全部` → `ぜんぶ`
- `残り` → `のこり`
- `余計なカード` → `使わないカード`
- `方程式を作ろう` → `式を作ろう`
- `定員` → `1 グループの人数`
- `実際の人数は同じ` → `人数は同じです`

## 题干模板

```text
A は何個かわかりません。
あとで B 個もらいました。
今は C 個です。
はじめは何個？
```

```text
1 回分のねだんを △ 円にします。
たけしくんは 2 回分と 1 円。
花子さんは 1 回分と 4 円。
2人の代金は同じです。
式を作ろう。
```

## UI 层约定

当前 UI 会在日语模式下自动：

- 把题干按句号、问号、感叹号和读点拆成短行。
- 高亮数字、单位、`△`、`+`、`−`、`×`、`÷`、`=`。
- 同一套处理用于关卡题干、门槛题、练习区题目和练习提示。

这只能降低视觉负担，不能替代内容改写。新增关卡时仍应先按本文件写短句。
